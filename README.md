# Helmholtz Equation in Bounded Domains: Resonant Solutions via the Limiting Absorption Principle

Finite element experiments for the interior Helmholtz problem

$$\Delta u + k^2 u = F(x, k) \quad \text{in } \Omega, \qquad u = 0 \quad \text{on } \partial\Omega,$$

in the **resonant regime**, where $k^2$ coincides with a Dirichlet eigenvalue of $-\Delta$ on $\Omega$. In this case the operator $\Delta + k^2$ has a nontrivial kernel, the classical solution fails to be unique, and the problem is only solvable when the source satisfies a Fredholm compatibility condition. The limiting absorption principle (LAP) — continuing $k$ into the complex plane and letting the perturbation tend to zero — singles out one particular weak solution, and this repository computes it numerically.

Three planar test cases are included: a rectangle, a circle, and an ellipse.

## Method

Each `main_*.jl` script follows the same pipeline.

1. **Discretization.** Read a Gmsh mesh, build a P1 Lagrange space with homogeneous Dirichlet conditions, and assemble the stiffness and mass matrices

   $$K_{ij} = \int_\Omega \nabla\varphi_i \cdot \nabla\varphi_j \, dx, \qquad M_{ij} = \int_\Omega \varphi_i \varphi_j \, dx.$$

2. **Eigenpairs.** Solve the generalized eigenproblem $K\varphi = \lambda M\varphi$ with `Arpack.eigs` (`which=:SM`) for the lowest modes, and set $k = \sqrt{\lambda_j}$ for the resonance under study. Using the *discrete* eigenvalue makes $A = K - k^2 M$ exactly singular in floating point, so that $\ker(A)$ is clean and $\text{range}(A) = \ker(A)^\perp$ holds to machine precision.

3. **Orthogonalization.** Project the source onto the orthogonal complement of the eigenspace,

   $$\tilde F = F - \sum_j c_j \psi_j, \qquad c_j = \langle F, \psi_j \rangle,$$

   so that the discrete system becomes compatible. The sum runs over the full (possibly degenerate) eigenspace associated with $k^2$.

4. **Particular solution.** Solve $A u = b$ with GMRES started from $u_0 = 0$. 

5. **LAP correction.** Recover the kernel coefficients from the constraint derived in the singular perturbation analysis,

   $$2k \langle u_{\text{special}}, \psi_j \rangle + 2k\, a_j \|\psi_j\|^2 = \left\langle \frac{\partial F}{\partial k}, \psi_j \right\rangle,$$

   and assemble the final solution $u = u_{\text{special}} + \sum_j a_j \psi_j$.

## Test cases

| Directory | Domain | Resonance | Source | Kernel |
|---|---|---|---|---|
| `test/test_rectangle/` | $[0,\pi]^2$ | $k^2 = 5$ | $F = xy$ | 2-dimensional: $\sin x \sin 2y$, $\sin 2x \sin y$ |
| `test/test_circle/` | unit disk | $k^2 = \lambda_2 \approx 14.69$ | $F = k e^{x^2+y^2}$ | 2-dimensional: the $m=1$ pair |
| `test/test_ellipse/` | $x^2/4 + y^2 \le 1$ | $k^2 = \lambda_1 \approx 3.56$ | $F = k\cos(x+y)$ | 1-dimensional: the ground state |

The square and the disk are degenerate: the eigenvalue $\lambda = 5$ on $[0,\pi]^2$ arises from $1^2 + 2^2 = 2^2 + 1^2$, and the second Dirichlet eigenvalue of the disk carries the two $m = 1$ modes. Within a degenerate eigenspace `eigs` returns an arbitrary orthonormal basis, so the individual coefficients $a_j$ are basis-dependent; only the combined field $\sum_j a_j \psi_j$ is invariant. The ellipse is non-degenerate, its eigenvalues being given by zeros of Mathieu functions.

The disk case is a useful sanity check: the Gaussian source is radially symmetric and therefore $L^2$-orthogonal to the antisymmetric $m=1$ modes, so both coefficients vanish and the LAP solution reduces to $u = u_{\text{special}}$.

## Layout

```
test/
├── runtests.jl
├── test_circle/     geo_circle.jl     main_circle.jl
├── test_ellipse/    geo_ellipse.jl    main_ellipse.jl
└── test_rectangle/  geo_rectangle.jl  main_rectangle.jl
Project.toml  Manifest.toml
```

Each `geo_*.jl` builds the geometry with the Gmsh built-in kernel, tags the boundary curves as `"boundary"` and the surface as `"domain"`, generates a 2-D mesh with characteristic length `lc = 0.05`, and writes a `.msh` file next to itself. Each `main_*.jl` reads that mesh and runs the pipeline above.

Meshes (`*.msh`), VTK output (`*.vtu`) and figures (`*.png`) are not tracked; they are regenerated by running the scripts.

## Requirements

Julia 1.9 or later. Dependencies are pinned in `Project.toml` / `Manifest.toml`:

[Gridap](https://github.com/gridap/Gridap.jl), [GridapGmsh](https://github.com/gridap/GridapGmsh.jl), [GridapMakie](https://github.com/gridap/GridapMakie.jl), [CairoMakie](https://github.com/MakieOrg/Makie.jl), [Arpack](https://github.com/JuliaLinearAlgebra/Arpack.jl), [IterativeSolvers](https://github.com/JuliaLinearAlgebra/IterativeSolvers.jl).

```bash
git clone https://github.com/Monkeys66/Helmholtz-bounded-domain-LAP-solution.git
cd Helmholtz-bounded-domain-LAP-solution
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

## Usage

Generate the mesh first, then solve. Taking the ellipse as an example:

```bash
julia --project=. test/test_ellipse/geo_ellipse.jl -nopopup
julia --project=. test/test_ellipse/main_ellipse.jl
```

The `-nopopup` flag suppresses the interactive Gmsh window; omit it to inspect the mesh in the Gmsh GUI before it is written. The solver scripts are written to be run interactively (VS Code, or `include` from the REPL), where the trailing `fig` renders in the plot pane. The blocks that draw the first three eigenfunctions side by side are present but commented out.

To refine the mesh, lower `lc` in the corresponding `geo_*.jl` and regenerate. Dirichlet eigenvalues computed with P1 elements converge from above at rate $O(h^2)$, so halving `lc` should shrink the error by roughly a factor of four.
